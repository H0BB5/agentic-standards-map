Status

Draft v0.1 specification, maintained by Mastercard according to its README (Apache-2.0, tag v0.1.0). The FIDO Alliance release of 2026-04-28 says Mastercard has contributed it to the Payments Technical Working Group. On 2026-10-13 the last commit on main is of 2026-04-20 (356c296, PR #23), v0.1.0 is the only tag, no release is listed, and the README header reads "Draft (v0.1). Maintained by Mastercard; open to multi-stakeholder contribution."

Relevance

The repository describes it as an "Open specification for cryptographic agent authorization in commerce"; the README defines a "layered SD-JWT credential format" giving cryptographic evidence that an agent's actions stayed within the scope the user delegated. Layers hold mandates (signed claims on checkout details or payment parameters) and user constraints; the merchant receives the checkout mandate (layer 3b, Autonomous mode).

The FIDO release says "Mastercard has contributed its Verifiable Intent framework, co-developed with Google and designed to work with AP2"; Google as co-developer: not found in the repository pages read, 2026-10-02.
