Relevance

The README says "x402 is an open standard for internet native payments."; the server answers 402 with a PAYMENT-REQUIRED header, the client replies with PAYMENT-SIGNATURE, and an http-message-signatures extension identifies the paying agent. The offer-and-receipt extension lets the server "cryptographically commit to the payment terms it presents in" accepts[] (the payment terms of the offer, not the commercial terms of the sale) and sign a receipt; it says "Wire shape and field placement are not considered stable". The FAQ describes the exact scheme as a push payment, "irreversible once executed".
