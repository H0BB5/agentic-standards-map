For agents and tools

The map in machine-readable form. These are plain files and standard web formats.

This site uses generic web mechanisms (JSON files, link rel=alternate, schema.org JSON-LD, a sitemap). It does not adopt any of the discovery mechanisms described in the map, so that the map does not take a side in what it maps.

How to cite

Cite the entry id and the date it was read.

The website is the living version and changes as venues move. Version 1.0 is the tag v1.0.0 of the repository; a DOI for each frozen snapshot is not issued yet, and until it is, cite the entry id, the date it was read and the commit shown in the footer of the page.

Counts

The numbers of sources quoted on the site (source references, distinct URLs, primary and third-party-only URLs) are produced by tools/count_sources.py, run on the files of the repository. A source reference is one use of a URL in the field sources or in a committed_next item; a distinct URL is counted once whatever the number of uses; a URL with a fragment is a different URL. The script counts URLs and does not check that they respond.

Updates

Each entry carries its own read date (the fields verified and status_as_of). The site is regenerated from the data at each commit of the repository; the newest verification date is 2026-10-14.

Corrections

Corrections and missing sources: open an issue on the repository.
